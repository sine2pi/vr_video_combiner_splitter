## 2026-08-06 - [Tkinter Thread-Safety and Cache Normalization]
**Learning:** Calling Tkinter GUI updates (like Text.insert, Text.config, and root.update_idletasks) from a background thread is highly thread-unsafe and triggers severe UI redrawing slowdowns, memory leaks, or random crashes. Also, caching file operations (like ffprobe metadata) using functools.lru_cache is ineffective if file paths are referenced using multiple representations (e.g., relative, absolute, dotted).
**Action:** Always buffer background thread logging into a thread-safe `queue.Queue` and process it in batches on the Tkinter main thread using a periodic `root.after` polling loop. Always normalize paths using `os.path.abspath(os.path.normpath(file_path))` before passing them to a cached function to ensure cache hit reliability.
