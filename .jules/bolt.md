## 2026-06-21 - Tkinter GUI Thread-Safe Batch Logging
**Learning:** Updating a Tkinter Text widget directly from multiple background thread callbacks using `update_idletasks()` blocks/slows down the application's processing thread and causes substantial GUI lag. This is because every line of FFmpeg stdout triggers a rendering redraw in the Tkinter main loop. Normalizing video file paths before executing cached functions (like `get_video_info`) also prevents duplicate process spawning for the same files accessed via different relative/absolute paths.
**Action:** Use `queue.Queue` to store logs thread-safely in background threads, and poll this queue every 100ms in the main thread using `root.after` to batch append and redraw the UI once per batch. Normalize video file paths using `os.path.abspath(os.path.normpath(file_path))` to maximize LRU cache hits.
