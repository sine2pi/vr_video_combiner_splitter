## 2026-06-22 - Tkinter Thread Safety and Log Queue Optimization
**Learning:** Direct UI updates (e.g., updating Text widgets or calling update_idletasks()) from a background thread in Tkinter violate Python's single-threaded GUI event loop model, leading to thread-safety violations, visual stuttering, or full application deadlocks. Caching using raw paths can miss cache hits due to path string variations (e.g., relative vs. absolute vs. normalized paths).
**Action:** Use a thread-safe `queue.Queue` to store messages from background threads and poll the queue periodically on the main thread using Tkinter's `root.after()`. Batch log messages during polling to reduce redraw overhead, filter out empty stdout lines, limit text widget line capacity to 1000 lines, and normalize all paths before cache-lookup to maximize LRU cache hits.
